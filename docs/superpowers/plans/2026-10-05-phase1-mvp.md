# Eggless Phase 1 MVP Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A private, phone-first web page that searches a Google map for breakfast cafés and shows each one's menu with egg dishes hidden, ranked by dishes a non-egg-eater can order as they are.

**Architecture:** Next.js App Router on Vercel. `/api/search` runs one Places search and joins it with menus cached in Neon Postgres; `/api/menu` extracts uncached menus with the pipeline proven in the Phase 0 spike, now split into `lib/menu/*`. Route handlers are thin wrappers over pure handler functions in `lib/handlers/*` so they can be tested without Next. A secret-link cookie gates everything.

**Tech Stack:** Next.js 16, React 19, TypeScript, Tailwind 4, `@vis.gl/react-google-maps`, Vercel AI SDK 7 (`ai`, `@ai-sdk/anthropic`), zod 4, cheerio, Drizzle ORM + `@neondatabase/serverless` (Pool, for transactions), Vitest + `@electric-sql/pglite` (in-process Postgres for DB tests) + `@testing-library/react`.

**Spec:** [docs/superpowers/specs/2026-10-05-phase1-mvp-design.md](../specs/2026-10-05-phase1-mvp-design.md). Background: [docs/ARCHITECTURE.md](../../ARCHITECTURE.md), [docs/SPIKE.md](../../SPIKE.md). Reference implementation of the pipeline: [scripts/spike.ts](../../../scripts/spike.ts).

## Global Constraints

- Only the Google place ID is stored from Google. Website URLs reach `/api/menu` only inside signed tokens.
- User-Agent: `EgglessBot/0.1 (personal project; one fetch per cafe)` (ASCII only).
- Fetch limits: 8 s timeout; 2 MB for HTML; 10 MB for PDFs; 5 MB per image, images under 60 KB ignored; at most 3 PDFs and 4 images per café.
- Model from `LLM_MODEL`, default `claude-haiku-4-5`; `temperature: 0`; `PROMPT_VERSION = 1`; optional header `anthropic-workspace-id` from `ANTHROPIC_WORKSPACE_ID`.
- Expiry: `ok` and `no_breakfast` 30 days; `no_menu_found` and `fetch_failed` 7 days. Pending lease 2 minutes.
- Token lifetime 10 minutes. Cookie `eggless_key`: httpOnly, Secure, SameSite=Lax, max-age 31536000.
- Headline count = `no_egg` and `substantial`. Ranking: options desc, adaptable desc, rating desc, unknown menus last.
- Copy, verbatim: "This is a private page. Ask Roman for the link." · "Daily search limit reached, try again tomorrow" · "Location is off; pan the map and tap Search this area" · "Reading the menu…" · "Menu not online" · "No breakfast menu" · "Couldn't read the menu" · "A preference filter, not an allergen guide. It only reads what the menu says."
- Next 16 renamed `middleware.ts` to `proxy.ts`; the spec's middleware is `proxy.ts` here.
- No network or LLM calls in `npm test`.

## Review Focus

1. **Transient LLM failure** (Anthropic 429/529/overloaded, network timeout): the café must not be cached as `fetch_failed` for 7 days; the claim is released and the card shows "Couldn't read the menu" with a retry. Test in Task 9.
2. **Page left open past the 10-minute token life**: tapping retry on a card with an expired token re-runs the search instead of looping on 401s. Test in Task 10.
3. **Repeated taps on "Search this area" while menus are still loading**: the same place is never sent to `/api/menu` twice at once, and results from an older search do not overwrite a newer one. Test in Task 10.
4. **Sparse Places data** (zero results; a place with no rating, no `openNow`, no website): the list shows "No cafés found here" for zero results, and cards omit missing fields instead of showing "undefined". Tests in Tasks 8 and 11.
5. **Hostile or odd responses from café sites** (HTML over 2 MB, a redirect chain into a private address, binary content served as `text/html`): the café ends as `fetch_failed` or `no_menu_found`; the request never throws to the client. Tests in Tasks 2 and 5.
