# Eggless Phase 2 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Russian interface and dish names, a full-screen map with pin previews, café photos (website image first, Google fallback), and chain detection with a filter.

**Architecture:** Extends the Phase 1 app in place. Copy moves into `lib/i18n/ru.ts`; extraction returns Russian fields (prompt v2) and a backfill script translates cached dishes; `collect.ts` also finds the site's share image; `/api/search` adds chain flags and signed Google photo references; a new `/api/photo` route redirects to Google photos under a daily cap; the UI gains photos, a chain filter and a full-screen map state.

**Tech Stack:** As Phase 1 (Next.js 16, React 19, Tailwind 4, `@vis.gl/react-google-maps`, AI SDK 7, zod 4, cheerio, Drizzle + Neon / PGlite, Vitest).

**Spec:** [docs/superpowers/specs/2026-10-07-phase2-russian-photos-chains-design.md](../specs/2026-10-07-phase2-russian-photos-chains-design.md). Phase 1 plan for conventions: [2026-10-05-phase1-mvp.md](2026-10-05-phase1-mvp.md).

## Global Constraints

- All user-visible copy comes from `lib/i18n/ru.ts`, exactly as in spec §3.1's table. No copy literals in components, handlers or the proxy.
- `PROMPT_VERSION = 2`. Egg classification stays on the English text.
- Google data rules unchanged: only place IDs stored; photo references never stored; Google key never reaches the browser.
- Photo tokens: HMAC like menu tokens, 10-minute life. `/api/photo` width clamped to 200–800, default 400; `PHOTO_DAILY_CAP` default 100, UTC day.
- Website image accepted only if `https:`, not a skipped host, not matching `logo|icon|favicon|avatar|sprite|placeholder|default`, not `.svg`, declared `og:image:width` ≥ 400 when present, fetched check: 2xx, `image/*`, ≥ 30 KB, ≤ 5 MB.
- Chain filter storage key `eggless.hideChains`; default off.
- Keep handler/route split, injected deps, PGlite DB tests and no-network `npm test` from Phase 1.

## Review Focus

1. **Russian name identical to the English** (e.g. a brand like "Açaí Bowl" left as-is, or differing only in case): the card shows one line, not the same name twice. Test in Task 7.
2. **A Google photo token that expired or was refused** (page left open > 10 min, or the daily cap hit): the card shows no photo area, never a broken-image icon. Test in Task 7.
3. **Opening and closing the full-screen map repeatedly, then pressing back**: back closes full screen once, and repeated open/close does not pile up history entries that trap the user on the page. Test in Task 8.
4. **Storage blocked** (private mode, `localStorage` throws): the «Без сетей» filter still works for the session and the page does not crash. Test in Task 7.
5. **Backfill running while a café's menu is re-extracted** (its dishes replaced with new IDs mid-run): the backfill skips the vanished rows without crashing and the next run translates the new ones. Test in Task 4.
